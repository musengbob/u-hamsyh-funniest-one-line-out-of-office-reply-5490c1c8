## The reply

> I'm away until Monday; my auto-reply has taken over and, frankly, it's outperforming me.

A turn on the away message itself: the auto-reply has taken over the job — and it's better at it than I ever was. Reads like a real message a person would gladly switch on, lands on the first read, and needs no name or signature to stand alone.

## How it works

`main.ts` writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to a local `output/` directory when the variable is unset):

```sh
node main.ts
```
